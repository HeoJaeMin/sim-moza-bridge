Sim MOZA Bridge

시뮬레이싱 게임 텔레메트리를 MOZA Pit House로 전달하고, 패킷 보정, 로깅, HUD, 주행 분석을 실험하는 Rust 기반 도구입니다.

공식 MOZA 또는 EA 도구가 아닙니다. 현재 가장 안정적인 대상은 F1 25 UDP 텔레메트리입니다.

지원 프로필

브리지는 게임별 입력 방식이 다르기 때문에 `--game` 프로필로 동작을 나눕니다. F1 25는 UDP를 직접 읽을 수 있지만, ACE/ACR/LMU는 공유 메모리 또는 플러그인 어댑터가 필요합니다.

자동 감지autoUDP 패킷 기반 감지현재 F1 25를 감지하고, 알 수 없는 UDP는 그대로 전달합니다.
F1 25f1-25UDP 그대로 전달 + F1 패킷 보정명시적으로 F1 25만 사용할 때 선택합니다.
일반 UDPgeneric-udpUDP 그대로 전달외부 도구가 이미 MOZA가 이해할 수 있는 UDP를 만들 때 사용합니다.

요구 사항

Windows PC

대상 게임과 MOZA Pit House가 실행되는 PC가 필요합니다.

실행 파일

집에서 사용할 때는 sim-moza-bridge.exe만 있으면 됩니다.

Rust

소스에서 직접 빌드하거나 개발할 때만 Rust 1.95 이상이 필요합니다.

F1 25 설정

F1 25 텔레메트리 설정에서 아래처럼 설정합니다. MOZA Pit House는 보통 F1 25 입력으로 22025 포트를 기대하므로, 브리지는 기본적으로 20777에서 받아 22025로 전달합니다.

항목값
UDP TelemetryOn
UDP IP Address127.0.0.1
UDP Port20777
UDP Send RateHUD 부드러움 기준 60Hz 권장, 안정성 우선이면 20Hz, 120Hz는 실험용
UDP Format2025

사용법

기본 그대로 전달

cargo run -- --listen 20777 --moza-port 22025 --mode passthrough

배포된 exe로 실행

.\sim-moza-bridge.exe --listen 20777 --moza-port 22025 --mode passthrough

F1 25 타이어 웨어 순서 보정

cargo run -- --listen 20777 --moza-port 22025 --mode remap --fix-tyre-wear-order

외부 익스포터 UDP 전달

cargo run -- --game generic-udp --listen 20777 --moza-port 22025 --mode passthrough

입력 로깅, HUD, 분석

F1 25의 PacketCarTelemetryData에서 스로틀, 브레이크, 조향, 클러치, DRS, REV, 속도, 기어, RPM, 온도 값을 추출합니다.

CSV 로깅
cargo run -- --mode remap --fix-tyre-wear-order --input-log inputs.csv

브라우저 HUD
cargo run -- --hud-http 8765 --input-log inputs.csv
브라우저에서 http://127.0.0.1:8765를 엽니다.

랩 분석
--corner-log는 구간별 CSV를 누적하고, --analysis-report는 최신 완료 랩 분석 Markdown을 덮어씁니다.

텔레메트리 호환 차이

F1 25 UDP는 바이너리 프로토콜이고, MOZA Dash Studio는 v1/gameData/Rpm, v1/gameData/TyreWearFL 같은 이름 기반 값을 노출합니다. 두 형식은 항상 1:1로 맞지 않습니다.

영역문제현재 브리지 동작
휠 배열F1 배열은 RL, RR, FL, FR 순서이고 MOZA 키는 FL, FR, RL, RR 이름 기준입니다.내부 파서는 코너 이름으로 매핑합니다. 전달 중 실제 수정하는 값은 현재 타이어 웨어뿐입니다.
단위와 파생값ERS 에너지, 연료, REV 라이트 퍼센트, 온도 등은 게임별 원본 값입니다.로컬 HUD/리포트에서는 일부 표시용 값을 파생합니다.
랩과 차간F1에는 앞차/선두와의 차이가 있지만 Pit House 키가 항상 있는 것은 아닙니다.로컬 분석 리포트에서 사용합니다. Pit House에 새 키를 만들 수는 없습니다.
비-F1 게임ACE, ACR, LMU는 F1 UDP 패킷 구조가 아닙니다.네이티브 어댑터가 필요하고, generic-udp는 외부 익스포터가 만든 패킷만 전달합니다.

F1 25 wheel array는 0=RL, 1=RR, 2=FL, 3=FR입니다. Mission R 대시에 타이어 웨어가 앞뒤/좌우로 바뀌어 보일 때만 --fix-tyre-wear-order를 켜고 확인해야 합니다.

구현됨
