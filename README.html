Sim MOZA Bridge

시뮬레이싱 UDP 텔레메트리를 받아 MOZA Pit House로 넘기는 Rust 기반 브리지입니다. 일반 실행은 자동 감지로 시작하고, F1 25가 감지되면 MOZA Pit House 정합성에 맞는 보정을 자동 적용합니다.

이 프로젝트는 MOZA 또는 EA의 공식 도구가 아닙니다.

요구 사항

  • 대상 게임과 MOZA Pit House가 실행되는 Windows PC
  • 소스에서 직접 빌드할 경우 Rust 1.95 이상
  • F1 25 게임 내 UDP 텔레메트리 활성화

F1 25 설정

항목값
UDP TelemetryOn
UDP IP Address127.0.0.1
UDP Port20777
UDP Send Rate60Hz 권장, 안정성 우선이면 20Hz
UDP Format2025

실행

기본 실행:

cargo run

배포된 실행 파일:

.\sim-moza-bridge.exe

포트를 바꿔야 할 때만 지정합니다.

cargo run -- --listen 20777 --moza-port 22025

런타임 통계와 패치 로그를 보고 싶을 때만 debug를 켭니다.

cargo run -- --debug

브리지가 시작되면 로컬 HUD가 기본 브라우저로 자동 열립니다.

http://127.0.0.1:8765

HUD에는 속도, 기어, RPM, REV LED, 입력 추적, 타이어/브레이크 상태, 앞차/뒤차/선두 gap, 연료, ERS, 손상 패널이 기본으로 표시됩니다.

동작 방식

  • 127.0.0.1:20777에서 UDP 텔레메트리를 받습니다.
  • 127.0.0.1:22025로 MOZA Pit House에 전달합니다.
  • 127.0.0.1:8765에 브라우저 HUD를 띄우고 기본 브라우저로 엽니다.
  • F1 25 패킷이 감지되면 PacketCarDamageData를 F1 24 호환 레이아웃으로 자동 변환합니다.
  • MOZA 대시의 TyreWear* 값이 100에 고정되는 문제를 피하기 위해 CarDamage 호환 변환은 기본으로 켜져 있습니다.
  • 알 수 없는 UDP 패킷은 파싱하지 않고 그대로 전달합니다.
